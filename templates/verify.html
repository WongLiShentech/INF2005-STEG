Check whether a file carries a valid hidden record, who signed it, and whether the picture has been altered since.

1. File to check — the one you received

Usually a protected file someone sent you, image, sound or video. Try an unprotected one too, to see it report Payload Missing.

2. Original cover object — optional, for comparison

If you still have the file as it was before protection, add it here and the two will be shown side by side. The verdict does not depend on it: verification works from the received file alone, which is the point — the person checking a file usually does not have the original.

3. Hiding password — the same one used to protect it

Get this wrong and the tool looks in the wrong part of the picture, reporting Wrong Start Location. This is not the signing key — that is step 5.

4. Start location — optional

Only needed if whoever protected the file chose the start location by hand instead of letting the password decide. Get it wrong and the result is Wrong Start Location, the same as an incorrect password.

5. Public key — who you expect signed it

Already on this machine, so there is nothing to upload. Pick demo_public.pem for a normal check, or other_public.pem to watch a genuine file be rejected because it was not signed by that key.

This key checks the signature only; it never decrypts anything. If the message was encrypted, the cipher key comes from your password in step 2, not from here — signing answers who sent this, encryption answers who may read it.
